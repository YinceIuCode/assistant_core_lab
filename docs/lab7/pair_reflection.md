# Google PAIR Guidebook Reflection

1. **Used today (Feedback + Control):** Our chat interface pairs explicit per-message `👍`/`👎` feedback buttons with collapsible verified source badges and a clear disclaimer to verify critical academic rules with the Training Office, keeping users in control of both evaluating and escalating AI answers.
2. **Future improvement (Errors + Graceful Failure):** Instead of only displaying generic backend error banners when requests fail or confidence is low, we will introduce structured graceful-failure states that preserve the user's failed query for one-click retry and surface direct Training Office contact links or manual handbook search fallbacks.
